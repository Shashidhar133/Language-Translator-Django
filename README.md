# 🌐 Language Translator Django

A simple and user-friendly language translation web application built using Python and Django.

## ✨ Features

- 🌍 Translate text between multiple languages
- 🔄 Easy-to-use translation interface
- 🐍 Built with Python and Django
- 🌐 Uses Google Translator through `deep-translator`
- 👤 Stores translation history for users
- 📱 Clean and responsive interface
- ⚡ Fast translation

## 🛠️ Technologies Used

- Python
- Django
- HTML
- CSS
- JavaScript
- SQLite
- deep-translator
